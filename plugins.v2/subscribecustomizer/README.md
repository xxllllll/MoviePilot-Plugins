# 订阅参数定制

按规则自动修改 MoviePilot 订阅参数。适合把不同媒体类型固定到不同订阅策略，例如韩剧固定 1080p，综艺 / 真人秀只使用指定站点并追加关键词。

## 功能

- 新增订阅后自动执行规则。
- 使用 Vue 可视化表格维护规则。
- 支持单个已有订阅的预览与手动应用。
- 支持按站点名解析为订阅字段 `sites`。
- 保存配置不会自动批量修改已有订阅。

## 安装与启用

1. 将插件目录放入 MoviePilot 插件仓库：

   ```text
   plugins.v2/subscribecustomizer/
   ```

2. 在 MoviePilot 插件市场安装插件。
3. 进入插件配置页，打开“启用插件”。
4. 新增或导入规则后保存。

## 规则结构

每条规则包含：

```json
{
  "name": "规则名称",
  "enabled": true,
  "priority": 10,
  "match": {},
  "set": {}
}
```

执行顺序：

- 只执行启用的规则。
- 按 `priority` 从小到大执行。
- 后执行的规则可以覆盖前面规则写入的同一字段。
- 同一条规则内，已填写匹配条件之间为 AND。
- 多值匹配字段内部为 OR。

## 匹配字段

| 字段 | 说明 |
| --- | --- |
| `type` | 媒体类型，例如 `电影`、`电视剧` |
| `title_regex` | 标题正则，唯一的标题模糊匹配方式 |
| `category_any` | 任一媒体分类命中 |
| `genre_any` | 任一风格命中 |
| `country_any` | 任一地区命中 |
| `language_any` | 任一语言命中 |
| `username` | 订阅用户 |

多值字段匹配前会去除首尾空格并统一英文大小写，匹配方式为精确匹配，不做包含匹配。

## 写入字段

| 字段 | 说明 |
| --- | --- |
| `quality` | 质量 |
| `resolution` | 分辨率 |
| `effect` | 特效 |
| `include` | 包含关键词 |
| `exclude` | 排除关键词 |
| `sites` | 站点 ID 列表 |
| `site_names` | 站点名称列表，自动解析为 `sites` |
| `filter` | 过滤规则 |
| `filter_groups` | 过滤规则组 |
| `downloader` | 下载器 |
| `save_path` | 保存路径 |
| `search_imdbid` | 是否使用 IMDb ID 搜索 |
| `custom_words` | 自定义识别词 |
| `media_category` | 自定义媒体类别 |

空动作字段视为未设置，不会清空已有订阅字段。

## 示例规则

### 韩剧固定 1080p

```json
{
  "name": "韩剧固定 1080p",
  "enabled": true,
  "priority": 10,
  "match": {
    "type": "电视剧",
    "country_any": ["KR", "韩国"]
  },
  "set": {
    "resolution": "1080p"
  }
}
```

### 综艺 / 真人秀只订阅观众并包含正片

```json
{
  "name": "综艺真人秀只订阅观众正片",
  "enabled": true,
  "priority": 20,
  "match": {
    "type": "电视剧",
    "genre_any": ["综艺", "真人秀"]
  },
  "set": {
    "site_names": ["观众"],
    "include": "正片"
  }
}
```

## 注意事项

- 示例规则不会默认启用；配置页中的“导入示例规则”按钮只导入示例，保存后才生效。
- `site_names` 必须与当前站点名称完全一致。
- 同一规则中任一站点名解析失败时，该规则整条跳过。
- 第一版只支持单个已有订阅预览 / 应用，不提供批量应用全部订阅。
- 保存配置不会自动修改已有订阅。
- 禁用插件后，不再自动修改新订阅。
