# MoviePilot-Plugins - SubscribeCustomizer

本仓库只发布一个 MoviePilot V2 插件：订阅参数定制。

插件市场地址：

```text
https://github.com/xxllllll/MoviePilot-Plugins
```

插件 ID：

```text
SubscribeCustomizer
```

插件目录：

```text
plugins.v2/subscribecustomizer
```

用途：按可视化规则自动定制媒体订阅参数，例如韩剧固定 1080p，综艺 / 真人秀只使用“观众”站点并包含“正片”关键词。
